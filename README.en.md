## Engineering focus

Connecting backend engineering with AI systems, from traffic management to model training, inference services, and Agent applications.

| Area | Scope |
| :--- | :--- |
| **Go / Python** | Backend services, CLIs, developer tools, and AI applications |
| **API gateways** | Protocol proxying, routing, authentication, rate limiting, and load balancing |
| **AI gateways** | Model integration, request routing, API governance, and observability |
| **LLM training & inference** | Model training, inference services, experiments, and evaluation |
| **Agent RL** | Agent reinforcement learning, reward design, and evaluation |
| **Agent applications** | Orchestration, tool use, MCP, memory, and interaction |

Public examples are featured below. The [AI / LLM / Agent casebook](docs/casebook.md) will add public AI gateway, LLM training and inference, and Agent RL case studies as materials become available. Notes in Chinese.
